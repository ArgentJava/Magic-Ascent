# Magic Ascent
Project Magic Ascent is a 1-4 player TBS game with two overlapping gameplay components:
- A civ-like map where the player claims resource tiles, and uses resources to upgrade combat abilities.
- A character-centric card-battler (similar to hearthstone) where players use acquired abilities and cards to battle each other for resources and objectives on the map.
  When playing solo, the player will play against an AI opponent; multiplayer will support up to 4 players. Players lose when their HP is depleted (a total value that is carried over between card battles), or when a player   completes their specific win-condition. The last man standing is the victor.

The game is set in a high-fantasy setting with magi-punk components. Aesthetic focus will be on mixing bio-punk and magi-punk with deco-core to give the game an indulgent and dynamic design to complement gameplay.
